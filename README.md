# EduFlow — кейс для портфолио

`build.js` — сборка кейса. Её скачивает и выполняет Figma-плагин **EduFlow Case Builder** в файле eduflow:
блоки кейса появляются на странице «Кейс — EduFlow».

- Обновить кейс: в Figma запустить плагин (Plugins → Development → EduFlow Case Builder).
- Сохранить ручные правки блока: заблокировать его (замок в панели слоёв) — плагин его не тронет.
